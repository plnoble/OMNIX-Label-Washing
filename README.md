# OmniX 服装多语种智能洗标系统

OmniX 是一款专业的服装洗标、材质成分及洗涤护理术语多语种智能翻译与拼版排版工具。该系统旨在帮助服装制造企业、外贸商及采购团队快速、合规地生成符合各国家和地区标准的多语种洗涤标签。

## 🚀 核心特性

- **多语种智能解析与翻译**：内置由 GB/T 8685 (国标) & ISO 3758 (国际标准) 构成的 2,300+ 行业词汇对照库，结合大语言模型实现对非规范洗标的准确分拆和多语种输出。
- **所见即所得的物理洗标排版 (WYSIWYG)**：
  - **HLA 1:1 双排折页排版**：以 HLA 40x170mm 双面原件为基准，自动拼版，支持 180° 对折旋转与动态语言拼接，内置黑色裁切光标和对折虚线。
  - **单语言标签预览**：支持切换至独立的单语种洗标卡片进行精细预览。
- **Excel 批量导入与导出**：
  - 支持系统专属的 HLA 22列批量翻译模板，可将解析的语言结果以独立 Sheet 完美导出。
  - 支持基础的双列对照翻译表解析与生成。
- **PDF & 图像智能 OCR 入库**：通过多模态大模型对印厂 PDF 或实物洗唛图片进行智能识别，并可通过“词库进化”功能一键合并入库，避免污染主词库。
- **完全离线运行**：利用单文件打包机制，可生成单个体积约 2MB 的独立 HTML 页面，排版人员双击即可离线使用所有本地规则翻译与排版渲染功能，免受网络和服务器故障干扰。

## 🛠️ 技术栈

- **前端核心**：React 19, TypeScript, TailwindCSS
- **打包器**：Vite 8, `vite-plugin-singlefile` (用于内联打包成单个 index.html)
- **解析库**：SheetJS (`xlsx`) 用于解析 Excel，`pdfjs-dist` 用于前端 PDF 转换
- **测试框架**：Vitest

## 📦 快速开始

### 运行环境
- Node.js >= 18.0.0
- npm >= 9.0.0

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run dev
```

### 生产环境单文件打包
```bash
npm run build
```
打包成功后，在 `dist/index.html` 会生成单文件网页。**您可以直接将此 `index.html` 复制到任何电脑上双击打开使用，无需配置任何服务器环境！**

## 🧪 自动化测试与检查

### 运行单元测试
单元测试覆盖了本地对照词库的各项基础操作（查询、新增、修改、重置及删除），运行以下命令：
```bash
npm run test
```

### 代码规范检查
```bash
npm run lint
```

## ⚠️ 隐私与安全说明
1. **API Key 安全**：系统完全在用户浏览器本地沙盒内运行，API 密钥不会上传至任何中转服务器。在设置中，用户可选择“不记住 API Key（仅当前会话有效）”，关闭页面即会自动销毁。
2. **数据保留**：所有导入的 Excel、PDF、临时自定义词库均保留在本地内存及 LocalStorage 中，通过点击“重置词库”可以一键抹除本地所有轨迹。
